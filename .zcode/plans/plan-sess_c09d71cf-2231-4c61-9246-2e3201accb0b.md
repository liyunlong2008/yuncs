# 重构：136 分批模型 + MA/MACD 多周期策略（对齐 VC_kxs 体系）

## 0. 玩法与约束（不变）
- 单交易对 ETH-USDT-SWAP、单进程、SQLite、动态出局线、进程内连续轮次；纸盘绝不影响真实账户；实盘一律以交易所为准（10s 对账）。
- 三模式共享策略代码与规则；回测必须过 compounding 复核才能换默认（AGENTS.md §7 红线）。
- 不引入新框架/服务；把现有"单仓整进整出"模型升级为"计划+分批(136)"模型。

## 1. 机械规则定稿（帖子语境的量化版，全部可配参）

周期栈：引擎 15m K 线（帖子要求信号周期最短 15m）；1H 序列由已收盘 15m 桶内部聚合。
指标：15m MA5/MA10 + MACD(12,26,9)；1H MA60（生命线）+ 1H 摆动高低点（支撑/压力/目标位）。

**方向模板（双向，默认全开，各自 enable 参数）**——"四个位置"机械化为四个入场模板：
- T1 底部反弹多：1H 收盘 < 1H MA60 且贴近近端摆动低点（支撑），15m 两情相悦金叉 → 做多，目标=生命线/摆动高点
- T2 高位回调空：1H 收盘 > 1H MA60 且贴近近端摆动高点（压力），15m 死叉 → 做空，目标=生命线/摆动低点
- T3 空中加油多：价在 1H MA60 上方、回踩生命线附近后 15m 金叉 → 顺势做多
- T4 确认位空：镜像（价在下方、反弹生命线附近后死叉 → 顺势做空）

**两情相悦**（同一根已收盘 15m bar）：MA5 上穿 MA10 且 MACD DIF 上穿 DEA（做多）；同向下穿（做空）。
**二次确认（"第一次错开"）**：首次两情相悦不进场；同向第二次出现且（做多）期间未跌破首次交叉后摆动低点才可进场（confirm=second 默认 / any 可关）。
**放量过滤**：触发 bar 量 > 前 20 根均量 ×2.5 → 不进场；持仓遇放量反向大 bar → 直接全平（"放量大反向直接止盈"）。
**高周期反向**：1H 收盘穿越生命线不利侧确认，或反向两情相悦 → 清仓。

**136 分仓（完整实现）**：
- 首次进场用 broker 统一口径算全仓目标 plan_eth（存 Position），L1=10%、L2=30%、L3=60%。
- L1：二次确认后进试单（即带保护止损：摆动失效/ATR）；L2：同向"再确认"（更高位再次两情相悦或突破进场摆动极值）补 30%；L3：趋势确认（向有利方向延伸 ≥1.2×ATR1H）补 60%；条件不满足则放弃后续批次；重启恢复的持仓不再补仓。
- 保证金逐批累加锁定（margin=名义/杠杆 线性精确），加权均价/累计保证金按 okx_math.liquidation_price 的"初始+追加保证金"官方口径重算强平价。

**离场（逐条对齐帖子）**：浮盈 ≥1×ATR → 止损移开仓价保本；此后追踪只朝有利方向移动；触及摆动高点/低点或生命线目标 → 部分止盈 50%（target_close_frac），剩余带追踪跑；放量大反向/高周期反向/出局线 → 全平剩余（出局线为引擎既有行为）。

## 3. 边界与风险（诚实声明）
- 帖子含主观成分（"支撑附近""错开"），机械版=一种可回测解读；结论以 compounding 表为准。
- 分批/部分平的纸盘会计按 OKX 线性口径；实盘以交易所对账为准（LiveBroker 路径不变）。
- 本策略属 EMA/MACD 交叉族（15m 历史上全败）——P5 闸门的意义所在；失败会明说，不粉饰。
- 不做：多交易对/新框架/挑战引擎语义改动；看板除 describe/部分平仓 reason 展示外不大改。
